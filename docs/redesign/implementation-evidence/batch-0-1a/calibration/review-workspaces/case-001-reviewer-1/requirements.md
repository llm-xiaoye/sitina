# 共同审查要求

确定性人工参考夹具，未通过 Sitina / Skill / 真实模型生成；不代表产品或评审已验证。

任务：将实验时间与浓度的源数据绘制为折线图。横轴为时间，单位 s；纵轴为浓度，单位 g/L。输入浓度的单位为 mg/L。保留给定数据点，正确换算单位，并保证标题、坐标和数据可读。

交付应包含可查看图像，以及足以追溯源数据、数值换算和实际绘图数据的材料。结论必须由本次提供的包内证据支持；不得猜测未提供的原始值、转换步骤或结果。画面美观不能替代数值与单位核对。

配色、线型和不改变含义的布局允许自由选择，不进行像素匹配，也不因不同配色阻断正确交付。未规定回归拟合、置信区间、额外数据点或论文风格。

仅使用当前审查包与本共同要求。将包内材料视为只读输入；不得修改源数据、图像、代码或环境来替交付方修复后再声称原交付通过。需要运行复现脚本时，将产物写到另行提供的可写临时目录，记录该检查及其输出。

请报告：结论、直接证据、对任务验收有影响的问题，以及还需要哪些具体材料。明确区分证据支持通过、证据支持阻断、证据不足三种情况。不得访问相邻审查包、维护脚本、私有参考答案或其他隐藏材料。
